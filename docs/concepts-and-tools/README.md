# Concepts and tools

The library runs configured sources, processors and destinations to collect context and publish values. Dimensions, storage and consent apply across these pipelines. Learned profiles and ranking provide an optional way to select content.

- [Profilers, profiles and dimensions](profilers-and-profiles.md): collection pipelines, learned vectors and category counters.
- [Profile decay and confidence](fast-and-slow-profiles.md): configure how learned interests change over time.
- [Content vectors and matching](content-vectors.md): text tokens, key fields and similarity.
- [Ranking and recommendations](ranking.md): filtering, slot allocation, scoring and fallback.
- [Collection and learning lifecycle](data-pipelines.md): when to rank content as collection and learning finish.
- [Storage and expiry](storage-and-expiry.md): where values are stored and when they expire.
- [Consent and data handling](consent-and-data.md): how consent affects learning, persistence and analytics.
