# Support

Start with the symptom you can see, then check the running version and configuration. The local examples provide a known starting point: if an example works but your integration does not, compare its metadata, consent state and candidate fields with yours.

- [Troubleshooting](troubleshooting.md): missing profiles, unexpected rankings, empty outputs and collection problems.
- [Morpht issue queue](morpht-issue-queue.md): report a problem, ask for help or request a change to Convivial Personalisation.

When reporting a problem, include the library version, the steps to reproduce it, and the expected and actual results. Use a small synthetic configuration and candidate list that reproduce the issue.
