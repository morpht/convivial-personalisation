# Morpht issue queue

Use Morpht's issue queue to report problems with Convivial Personalisation, ask for help or request a feature.

Morpht clients receive access to a project during onboarding. If you need access or are unsure which project to use, ask your Morpht contact.

## Raising an issue

Open an issue in your project and complete these fields:

- In **Tracker**, choose *Bug* for a fault, *Feature* for a proposed addition, or *Support* when you need help.
- Give the **Subject** a specific description, such as *Recommendations remain empty after browsing topic pages*.
- In **Description**, include the page URL, environment, browser and library version. Give the steps to reproduce the problem, the result you expected and what you observed. Add a screenshot when it helps show the issue, and say whether visitors are affected.
- Set **Priority** to *Urgent* for problems affecting visitors on the live site.

Add follow-up information to the same issue so the team can follow the investigation and its status in one place.

## Before raising one

Try the relevant [troubleshooting checks](troubleshooting.md). Compare the behaviour on your test environment and in the [local examples](../getting-started/README.md), and include any differences in the report.

For collection or ranking problems, provide a small configuration and synthetic candidate list that reproduce the behaviour. Note which profiles you requested and whether personalisation consent was granted.
