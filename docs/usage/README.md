# Usage

Connect personalisation to your content and visitor actions. These guides assume a working installation. Start with [Add the library to your site](browser.md) to install it, or use the short [collection and publishing example](../getting-started/installation.md).

- [Rank content](../ranking/README.md): select candidates with configured profiles or fallback.
- [Use profiles with different half-lives](fast-and-slow.md): an optional configuration for recent and longer-lived interests.
- [Build a recommendation block](recommendations.md): fetch candidates, rank and render results, then record interactions.
- [Prioritise an audience choice](audience.md): publish an explicit choice ahead of learned categories.
- [Suppress content after a completed goal](suppression.md): exclude or demote matching recommendations for a chosen duration.
- [Integrate with Drupal](drupal.md): reuse the site's engine and align page metadata with candidate fields.

The [real site configuration](../configuration/site-example.md) shows the complete field mapping. Use the [rank() reference](../reference/rank.md) when you need an option's exact behaviour or default.
