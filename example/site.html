Fast and slow recommendations

This example uses the complete site configuration. It learns a cat page, simulates five minutes passing, then learns a dog page. Fast has a one-minute half-life; slow has a one-hour half-life.

The comparison isolates similarity. The slow profile should retain more cat interest, while the fast profile responds more strongly to the recent dog page. Shared intent and other fields can also contribute to each score.

Data stays in memory. The example uses a separate site ID and disables diagnostic logging; analytics remain off.
